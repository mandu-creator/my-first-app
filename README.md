# 🖋️ 도장 해빗 트래커

다이어리에 도장을 찍듯 가볍게 쓰는 습관 기록 웹앱입니다.
습관을 며칠 놓쳐도 혼내지 않고 **"더 작게 다시 해보자"**고 제안하는, 게으른 완벽주의자를 위한 해빗 트래커예요.

## 주요 기능

- **도장 찍기**: 오늘 한 습관에 손글씨 느낌의 도장을 찍어 기록
- **작게 시작하기(미니 습관)**: 부담될 땐 "물 한 컵만", "딱 한 쪽만"처럼 줄인 버전으로 체크
- **타이머 습관**: 시간을 정해두고 하는 습관은 타이머로 기록
- **형광펜 색 구분**: 습관마다 다른 색으로 한눈에 구분
- **오늘 꼭 할 한 가지**: 하루의 집중 목표를 한 줄로 정하기

## 실행 방법

설치할 것 없이 `index.html` 파일을 브라우저로 열면 바로 실행됩니다.

## 파일 구조

```
index.html   화면 뼈대와 처음 보여줄 예시 데이터
style.css    디자인(색, 레이아웃, 도장 스타일)
app.js       기능(도장 찍기, 타이머, 저장 등)
```
기록은 브라우저(localStorage)에 저장되어 같은 기기·브라우저에서 이어서 쓸 수 있어요.
